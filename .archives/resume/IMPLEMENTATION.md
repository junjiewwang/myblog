# 在线简历页面 - 需求与实施记录

## 需求背景

在 docsify 博客中创建可分享的在线简历页面，投递简历时可直接发送链接，方便快捷。

## 设计目标

1. 面向中高级后端工程师（P6-P7）定位
2. HR 15 秒快速扫描能判断方向和级别
3. 技术负责人 1-3 分钟精读能评估技术深度
4. 信息脱敏，不暴露具体公司名称
5. 求真务实，不夸大

## 设计决策记录

| 决策 | 原因 |
|------|------|
| 顶部增加 Profile 摘要 | HR 5 秒判断方向匹配度 |
| 技能表用"掌握程度"替代"年数" | "源码级"比"3年"更有区分度 |
| 工作经历标注角色（Owner/核心开发） | 体现独立负责能力 |
| 项目表用"问题→方案→结果"格式 | STAR 格式让技术面试官快速评估 |
| 去掉游戏兴趣 | 对 P6-P7 级别面试无正向价值 |
| 暗色主题色从 #42d392 调为 #56d9a8 | 不刺眼但有活力的平衡点 |
| 全站配色收敛为 CSS 变量 | 一处修改全站生效，方便微调 |
