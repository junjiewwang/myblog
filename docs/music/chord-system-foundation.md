## 第 1 讲 · 材料：C 大调的音阶与音级

C 大调音阶，就是钢琴上**从 C 到下一个 C，全部白键**：

```
C  D  E  F  G  A  B  C
1  2  3  4  5  6  7  1
```

相邻音的距离（全音 / 半音）决定了它的"调式性格"：

```
C → D  全音
D → E  全音
E → F  半音
F → G  全音
G → A  全音
A → B  全音
B → C  半音
```

规律记作 **全 · 全 · 半 · 全 · 全 · 全 · 半**。这就是大调音阶的"配方"，任何一个大调都按这个间隔搭出来。

七个音级有传统命名，后面会反复用到：

| 音级 | 音 | 名称 | 简称 |
|---|---|---|---|
| I | C | 主音 | Tonic |
| II | D | 上主音 | Supertonic |
| III | E | 中音 | Mediant |
| IV | F | 下属音 | Subdominant |
| V | G | 属音 | Dominant |
| VI | A | 下中音 | Submediant |
| VII | B | 导音 | Leading tone |

**【思考】** 为什么偏偏是 E–F 和 B–C 之间是半音，其他相邻白键之间都是全音？

**【拆解】** 看钢琴：E 和 F 之间、B 和 C 之间**没有黑键**，所以天然就是半音；其余白键之间都隔着一个黑键，是整全音。大调的"全全半全全全半"不是人为规定，而是白键排列的物理事实。

## 第 2 讲 · 第一层：三和弦（骨架）

### 三度叠置回顾

从根音往上叠两个三度，就得到一个三和弦：

```
根音 → 三度 → 三音
三音 → 三度 → 五音
```

两个三度是"大三度 + 小三度"还是"小三度 + 大三度"，决定了和弦是大还是小。**关键看根音到三音**：大三度 → 大三和弦；小三度 → 小三和弦。

### C 大调的 7 个自然三和弦

在 C 大调内、只用白键堆三度，得到 7 个和弦：

| 音级 | 和弦 | 构成音 | 性质 |
|---|---|---|---|
| I | C | C E G | 大三 |
| ii | Dm | D F A | 小三 |
| iii | Em | E G B | 小三 |
| IV | F | F A C | 大三 |
| V | G | G B D | 大三 |
| vi | Am | A C E | 小三 |
| vii° | Bdim | B D F | 减三 |

记住这条性质序列：**大 · 小 · 小 · 大 · 大 · 小 · 减**（I ii iii IV V vi vii°）。所有大调都是这个序列，只是换根音。

**【思考】** 同样"堆两个三度"，为什么 I 级是 C E G（大三）、ii 级是 D F A（小三）？差别出在哪一段？

**【拆解】** 拆开看：I 级 C→E 是**大三度**（C-D 全、D-E 全 = 两个全音），所以是大三和弦；ii 级 D→F 是**小三度**（D-E 全、E-F 半 = 1.5 个全音），所以是小三和弦。**三度的那一层是"大"还是"小"，完全由音阶里这段距离决定**，而不是你手动去升降音。

## 第 3 讲 · 第二层：七和弦（色彩）

在三和弦上再叠一个三度，得到七和弦：

```
三和弦 1 3 5 → 再叠七度 → 1 3 5 7
```

### C 大调的 7 个自然七和弦

| 音级 | 和弦 | 构成音 | 性质 |
|---|---|---|---|
| I | Cmaj7 | C E G B | 大七 |
| ii | Dm7 | D F A C | 小七 |
| iii | Em7 | E G B D | 小七 |
| IV | Fmaj7 | F A C E | 大七 |
| V | G7 | G B D F | **属七** |
| vi | Am7 | A C E G | 小七 |
| viiø | Bm7♭5 | B D F A | 半减七 |

注意 V 级：它**天生就是属七（1 3 5 ♭7）**，不是大七。

**【思考】** 为什么偏偏是 V 级（G7）成了"属七"，而不是大七？它的七度音为什么是 ♭7？

**【拆解】** G 往上叠自然七度，落在白键 F 上。而 G 到 F 的距离是**小七度**（G-A-B-C-D-E-F，5 个全音），所以 G 的和弦七音天然是 ♭7（F），不是 F♯。只有把 F 硬升半音才会变成大七。**V 级生来就是属七，也因此生来就带"想解决"的张力**——这是下一讲的关键伏笔。

## 第 4 讲 · 第三层：功能和声（职责）

和弦不是孤立的，它们各有一份"工作"。按功能分三大类：

| 功能 | 含义 | 成员（C 调） | 感觉 |
|---|---|---|---|
| 主功能 T | 归属、起点终点 | I（C）、vi（Am）、iii（Em） | 稳、放松 |
| 下属功能 S | 离开、铺垫 | IV（F）、ii（Dm） | 走出去 |
| 属功能 D | 紧张、渴望解决 | V（G）、vii°（Bdim） | 紧绷、想回家 |

经典的运动方向是 **T → S → D → T**：从家出发，往外走，制造紧张，最后回家。这是 90% 流行歌的底层逻辑。

### 为什么 V → I 有"回家感"？

拿 G7 → C 看两个关键音：

```
G7 的 B（导音）   → 半音上行 →  C（主音）
G7 的 F（七音）   → 半音下行 →  E（三音）
```

**两个"半音倾向音"同时向主和弦靠拢**，就像两扇门同时合上，制造了强烈的"解决感"。这是功能和声里最重要的一个听觉现象。

**【思考】** 如果 G7 → C 这么有"回家感"，那 G7 → Cm（小调主和弦）为什么听起来也很顺、只是更黯淡？两个半音倾向音里，哪一个"走的路"变了？

**【拆解】** G7 的 B 仍然半音上行到 C，但 F 这次半音下行到 E♭（Cm 的 ♭3）。**决定"回家感"的是 B→C 的导音解决**，F→E♭ 只是决定"回的是大调的家还是小调的家"。这就是为什么属七既能为大调也能为小调"收尾"。

## 第 5 讲 · 第四层：常用和弦进行（语法）

和弦连起来的"套路"，是流行音乐最实用的语料库。以下全部用 C 调具体写出。

### 1. 4536251（抒情万能套路）

```
F → G → Em → Am → Dm → G → C
4    5    3    6    2    5    1
```

低音线是 **F - G - E - A - D - G - C**，整体是一条有起伏的下行线条，配上前半段"下属→属"的推进、后半段一路回落，情绪有起有落。

### 2. 卡农进行（15634145）

```
C → G → Am → Em → F → C → F → G
1    5    6    3    4    1    4    5
```

低音 **C - G - A - E - F - C - F - G**，是逐级下行（C-B-A-G-F…）的骨架，靠斜线/转位会让它流动得更明显。民谣、情歌的标配。

### 3. 1645（最简四和弦）

```
C → Am → F → G
1    6    4    5
```

四个和弦循环，好记好弹，无数歌就是它转出来的。

### 4. 1625（更柔的循环）

```
C → Am → Dm → G
1    6    2    5
```

把 4 换成 2（Dm），色彩更软、更"小调感"。

### 5. 251（爵士的骨架）

```
Dm7 → G7 → Cmaj7
ii7   V7    Imaj7
```

这是爵士乐的最小语法单位。注意它正好把三大功能串了一遍：**下属(ii) → 属(V) → 主(I)**，而且 5 度下行（D→G→C），是"最顺"的走法。

**【思考】** 4536251 前四个和弦 F-G-Em-Am，跟 251 的 Dm7-G7-C 相比，谁的"推进感"更强？为什么？

**【拆解】** 251 更强。因为 Dm7→G7 是纯五度下行（根音 D 跳到 G），属和弦又以**带七音的 G7** 形式出现，B 和 F 两个倾向音把"要解决"的张力拉满；而 4536251 里 G 只是三和弦，且 F→G 只是级进上行，张力平缓得多。**七音 + 五度下行 = 更强推进**，这是编曲里"想推情绪就上属七、想平稳就留三和弦"的依据。

## 第 6 讲 · 第五层：进阶——越界的"调味"

前面只用 C 大调白键，进阶则是**故意越界**，引入调外音，制造更强的色彩与方向。

### 1. 副属和弦（借别的调的属七）

规则：**给某个和弦，提前配一个"以它为目标的属七"**。比如想去 G，就用 G 的属七 D7：

| 副属和弦 | 记号 | 构成音 | 解决到 |
|---|---|---|---|
| V7/V | D7 | D F♯ A C | G |
| V7/ii | A7 | A C♯ E G | Dm |
| V7/vi | E7 | E G♯ B D | Am |
| V7/IV | C7 | C E G B♭ | F |

**【思考】** D7 里有个 F♯，可 F♯ 不在 C 大调里，为什么能用、还很好听？

**【拆解】** 因为 F♯ 是"**G 大调的导音**"。D7 本质是 G 调的属七，它把 G 调的导音借来，制造"往 G 靠"的冲动。**调外音的作用不是乱加，而是"指路"**——它告诉你下一个和弦要去哪。

### 2. 借用和弦（从 C 小调借）

从同主音小调（C 小调：C D E♭ F G A♭ B♭）借几个和弦，给大调注入暗色：

| 借用和弦 | 记号 | 构成音 | 效果 |
|---|---|---|---|
| ♭III | E♭ | E♭ G B♭ | 意外的开阔 |
| iv | Fm | F A♭ C | 突如其来的忧伤 |
| ♭VI | A♭ | A♭ C E♭ | 史诗感 |
| ♭VII | B♭ | B♭ D F | 摇滚的"下沉" |

C → Fm → C 是流行歌里"笑着笑着就哭了"的经典瞬间——F 变成 Fm，只动了 A→A♭ 一个音，情绪却翻了个面。

### 3. 属七的变化（把属七再"调味"）

在 G7（G B D F）基础上，动 5 音和 9 音：

| 记号 | 构成音 | 感觉 |
|---|---|---|
| G7♭9 | G B D F A♭ | 暗、狠，常推向小调主和弦 |
| G7♯9 | G B D F A♯ | Hendrix 味，大调藏小调 |
| G7♯11 | G B D F A C♯ | 爵士的"飘" |
| G13 | G B D F A E | 明亮饱满的收尾 |

**【思考】** G7♯9 的 ♯9 音 A♯，按音高其实等于 B♭——也就是 ♭3。为什么一个"属七"里能同时出现大三度(B)和小三度(B♭/A♯)两种"性格"？

**【拆解】** 这正是它迷人的地方：♯9 记谱上叫升九，听感上却是一个"藏起来的小三度"，跟和弦里的大三度 B 并排存在，制造"明亮与黯淡打架"的暧昧。所以 G7♯9 又狠又邪，是摇滚和布鲁斯的心头好。

## 第 7 讲 · 实战：听 + 弹 + 编

### 案例 1：三和弦性质听感训练

在键盘上依次按，闭眼听"明暗"：

```
C（大三，明亮） → Dm（小三，柔） → Em（小三） → F（大三，开阔）
→ G（大三，昂扬） → Am（小三，忧郁） → Bdim（减三，紧张）
```

训练目标：**不看琴键，只凭听感说出"大 / 小 / 减"**。减三和弦的"拧巴感"是最容易辨认的，先把它找出来。

### 案例 2：4536251 伴奏编排

左手弹根音，右手按和弦，循环：

```
F → G → Em → Am → Dm → G → C
```

进阶：把右手和弦换成七和弦，情绪立刻变"爵士"：

```
Fmaj7 → G7 → Em7 → Am7 → Dm7 → G7 → Cmaj7
```

同一个进行，**三和弦是"民谣"，七和弦是"沙发爵士"**——差别只在于多叠了一个七度。

### 案例 3：属七张力对比（最重要的听感训练）

固定弹 `C → G → C` 和 `C → G7 → C` 两组，反复对比：

```
C → G  → C    （三和弦属：平稳，推动感弱）
C → G7 → C    （属七：强烈想"回家"，F 音悬着等解决）
```

再进阶，对比 `G7 → C`、`G7♭9 → Cm`、`G13 → Cmaj7`，感受同一个"属功能"换上不同外衣后的松紧差异。

### 案例 4：《小星星》配和弦（完整示范）

旋律（C 大调）：

```
1 1 5 5 | 6 6 5 - | 4 4 3 3 | 2 2 1 -
```

配和弦（每小节一个，抓强拍音）：

| 小节 | 旋律 | 配和弦 | 理由 |
|---|---|---|---|
| 1 | 1 1 5 5 | C | 强拍 1、5 都是 C 和弦内音 |
| 2 | 6 6 5 | F 或 C | 6(A) 是 F 的三音，5(G) 是 F 的九音 |
| 3 | 4 4 3 3 | F → C | 4(F) 落在 F，3(E) 落在 C |
| 4 | 2 2 1 | G7 → C | 属七收尾，回到主 |

终止式写成 **C → F → G7 → C**，正好是 T → S → D → T 的完整闭环。

### 案例 5：给旋律配和弦的通用步骤

1. **定调**：找出旋律的主音，判断大调还是小调。
2. **分小节**：把旋律切成小节，标出每小节**强拍**上的音。
3. **选和弦**：从 I、IV、V、vi（最常用的四个）里，选**包含强拍音**的那个。
4. **定头尾**：开头用 I 建立调性；结尾用 **V → I** 收束。
5. **修低音**：让相邻和弦的根音尽量**级进或五度下行**，流动感就出来了。
