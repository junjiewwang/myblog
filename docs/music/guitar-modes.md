# 🎸 调式与组成音

> 调式 (Mode) 是以某个音为起点，按特定音程关系排列的音阶

## 七种自然调式

以 C 大调音阶 (C-D-E-F-G-A-B) 为基础，从不同音开始构建：

| 调式 | 起始音级 | 音程模式 | C 调示例 | 色彩 |
|:---:|:---:|------|------|------|
| **Ionian** | Ⅰ | 全-全-半-全-全-全-半 | C-D-E-F-G-A-B | 明亮、大调 |
| **Dorian** | Ⅱ | 全-半-全-全-全-半-全 | D-E-F-G-A-B-C | 爵士、蓝调 |
| **Phrygian** | Ⅲ | 半-全-全-全-半-全-全 | E-F-G-A-B-C-D | 西班牙、神秘 |
| **Lydian** | Ⅳ | 全-全-全-半-全-全-半 | F-G-A-B-C-D-E | 梦幻、飘逸 |
| **Mixolydian** | Ⅴ | 全-全-半-全-全-半-全 | G-A-B-C-D-E-F | 布鲁斯、摇滚 |
| **Aeolian** | Ⅵ | 全-半-全-全-半-全-全 | A-B-C-D-E-F-G | 忧伤、自然小调 |
| **Locrian** | Ⅶ | 半-全-全-半-全-全-全 | B-C-D-E-F-G-A | 不稳定、少用 |

### 调式通用音级公式

> 以大调 (Ionian) 的 `1 2 3 4 5 6 7` 为基准，其他调式通过升降变化

| 调式 | 音级公式 | 变化音 | 快速记忆 |
|:---:|:---:|:---:|------|
| **Ionian** | 1 2 3 4 5 6 7 | - | 大调基准，无变化 |
| **Lydian** | 1 2 3 #4 5 6 7 | #4 | 比大调**亮一点** → 升4 |
| **Mixolydian** | 1 2 3 4 5 6 ♭7 | ♭7 | 比大调**暗一点** → 降7 |
| **Dorian** | 1 2 ♭3 4 5 6 ♭7 | ♭3, ♭7 | 小调**亮一点** → 升6 (相对 Aeolian) |
| **Aeolian** | 1 2 ♭3 4 5 ♭6 ♭7 | ♭3, ♭6, ♭7 | 自然小调基准 |
| **Phrygian** | 1 ♭2 ♭3 4 5 ♭6 ♭7 | ♭2, ♭3, ♭6, ♭7 | 比小调**暗一点** → 降2 |
| **Locrian** | 1 ♭2 ♭3 4 ♭5 ♭6 ♭7 | ♭2, ♭3, ♭5, ♭6, ♭7 | 最暗 → 连5都降了 |

### 快速记忆技巧

**1. 大调系 vs 小调系**

```
大调系 (3 是大三度):        小调系 (♭3 是小三度):
┌─────────────────┐        ┌─────────────────┐
│ Lydian    (#4)  │ 最亮   │ Dorian   (♮6)   │ 较亮
│ Ionian    (基准) │        │ Aeolian  (基准)  │
│ Mixolydian (♭7) │ 较暗   │ Phrygian (♭2)   │
└─────────────────┘        │ Locrian  (♭2♭5) │ 最暗
                           └─────────────────┘
```

**2. 口诀记忆法**

```
"利大一米" - 大调系从亮到暗
Lydian → Ionian → Mixolydian
  #4       基准      ♭7

"多伊弗落" - 小调系从亮到暗  
Dorian → Aeolian → Phrygian → Locrian
  ♮6       基准       ♭2        ♭2♭5
```

**3. 特征音记忆**

| 调式 | 核心特征音 | 一句话记忆 |
|:---:|:---:|------|
| Lydian | **#4** | "升4飘仙气" |
| Mixolydian | **♭7** | "降7布鲁斯" |
| Dorian | **♮6** | "小调带大6，爵士味" |
| Phrygian | **♭2** | "降2西班牙" |
| Locrian | **♭5** | "减五不稳定" |

**4. 数字定位法**

> 调式 = 大调的第 N 级，N 就是调式的"位置数"

```
位置数:  1      2       3        4       5          6        7
调式:  Ionian Dorian Phrygian Lydian Mixolydian Aeolian Locrian

口诀: "一多弗利米伊落" (1234567)
```

**5. 变化音累积规律**

```
从 Ionian 开始，顺时针每走一步降一个音:

Ionian → Mixolydian → Dorian → Aeolian → Phrygian → Locrian
         ↓ ♭7         ↓ ♭3      ↓ ♭6      ↓ ♭2       ↓ ♭5

逆时针走一步升一个音:
Ionian → Lydian
         ↑ #4
```

## 调式与五度圈的关系

> 五度圈不仅展示调的关系，还隐藏着调式的规律

**核心规律**：在五度圈上，相邻的调共享 6 个音，只差 1 个音

```
五度圈顺时针方向 (升号增加):

  F     C     G     D     A     E     B
  ↓     ↓     ↓     ↓     ↓     ↓     ↓
Lydian Ionian Mixo  Dorian Aeolian Phrygian Locrian
 (+#4)  (基准) (-b7)  (-b3-b7) (-b3-b6-b7) ...
```

**调式明暗排序** (从亮到暗)：

```
最亮 ←────────────────────────────────→ 最暗

Lydian > Ionian > Mixolydian > Dorian > Aeolian > Phrygian > Locrian
  #4      基准      b7         b3,b7    b3,b6,b7   b2,b3,b6,b7  b2,b3,b5,b6,b7
```

## 调式实战应用

**1. 用五度圈快速找调式组成音**

> 例：找 D Dorian 的组成音

```
Dorian = 大调的第 2 级
D 是某大调的第 2 级 → 往逆时针走 1 格 → C 大调
所以 D Dorian = C 大调音阶从 D 开始
D Dorian: D-E-F-G-A-B-C
```

**2. 调式对应和弦**

| 调式 | 主和弦类型 | 常用和弦 |
|:---:|:---:|------|
| Ionian | 大三 | Imaj7, IVmaj7, V7 |
| Dorian | 小三 | Im7, IV7, IIm7 |
| Phrygian | 小三 | Im7, ♭II, ♭VII |
| Lydian | 大三 | Imaj7#11, II7 |
| Mixolydian | 属七 | I7, ♭VII, IVmaj7 |
| Aeolian | 小三 | Im7, ♭VI, ♭VII |

**3. 调式选择指南**

| 和弦进行 | 推荐调式 | 风格 |
|---------|---------|------|
| Im7 - IV7 | Dorian | 爵士、Funk |
| I7 - IV7 | Mixolydian | 布鲁斯、摇滚 |
| Im - ♭VII - ♭VI | Aeolian | 流行、民谣 |
| Imaj7 - II7 | Lydian | 融合爵士 |
