# 🎸 CAGED 和弦系统

> CAGED 是吉他学习的核心系统，由 C、A、G、E、D 五个开放和弦组成

## C 和弦

> 组成音：**C(1) - E(3) - G(5)**（根音 - 大三度 - 纯五度）

```
       1品    2品    3品
1弦 ║--○---|------|------║  E  [3]
2弦 ║--●---|------|------║  C  [1] *
3弦 ║--○---|------|------║  G  [5]
4弦 ║------|--●---|------║  E  [3]
5弦 ║------|------|--●---║  C  [1] * 低音
6弦 ║--x---|------|------║
```

## A 和弦

> 组成音：**A(1) - C#(3) - E(5)**（根音 - 大三度 - 纯五度）

```
       1品    2品    3品
1弦 ║--○---|------|------║  E  [5]
2弦 ║------|--●---|------║  C# [3]
3弦 ║------|--●---|------║  A  [1] *
4弦 ║------|--●---|------║  E  [5]
5弦 ║--○---|------|------║  A  [1] * 低音
6弦 ║--x---|------|------║
```

## G 和弦

> 组成音：**G(1) - B(3) - D(5)**（根音 - 大三度 - 纯五度）

```
       1品    2品    3品
1弦 ║------|------|--●---║  G  [1] *
2弦 ║--○---|------|------║  B  [3]
3弦 ║--○---|------|------║  G  [1] *
4弦 ║--○---|------|------║  D  [5]
5弦 ║------|--●---|------║  B  [3]
6弦 ║------|------|--●---║  G  [1] * 低音
```

## E 和弦

> 组成音：**E(1) - G#(3) - B(5)**（根音 - 大三度 - 纯五度）

       1品    2品    3品

5弦 ║------|--●---|------║  B  [5]

## D 和弦

> 组成音：**D(1) - F#(3) - A(5)**（根音 - 大三度 - 纯五度）

```
       1品    2品    3品
1弦 ║------|--●---|------║  F# [3]
2弦 ║------|------|--●---║  D  [1] *
3弦 ║------|--●---|------║  A  [5]
4弦 ║--○---|------|------║  D  [1] * 低音
5弦 ║--x---|------|------║
6弦 ║--x---|------|------║
```

> **图例**：○ 空弦 | ● 按弦 | x 不弹 | * 根音 | ║ 品丝

## 常用和弦进行

| 风格 | 和弦进行 | 示例歌曲 |
|------|---------|---------|
| 流行 | C - G - Am - F | 《晴天》《小幸运》 |
| 民谣 | G - D - Em - C | 《成都》《南山南》 |
| 摇滚 | E - A - B - E | 经典摇滚 |
| 卡农 | C - G - Am - Em - F - C - F - G | 卡农进行 |
