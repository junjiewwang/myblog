# 🎸 和弦转位与指板定位

> 掌握和弦音程结构，快速在指板上找到所有转位位置

## 和弦音程结构

### 三和弦构成原理

三和弦由三个音叠加而成：**根音、三音、五音**

| 和弦类型 | 音程结构 | 半音数 | 以 C 为根音 |
|:---:|:---:|:---:|:---:|
| **大三和弦** | 大三度 + 小三度 | 4 + 3 = 7 | C - E - G |
| **小三和弦** | 小三度 + 大三度 | 3 + 4 = 7 | C - E♭ - G |
| **减三和弦** | 小三度 + 小三度 | 3 + 3 = 6 | C - E♭ - G♭ |
| **增三和弦** | 大三度 + 大三度 | 4 + 4 = 8 | C - E - G♯ |

**记忆口诀**：
- 大三 = **大** 下 **小**（大三度在下）
- 小三 = **小** 下 **大**（小三度在下）
- 减三 = **小** + **小**（两个小三度）
- 增三 = **大** + **大**（两个大三度）

### 七和弦构成原理

七和弦 = 三和弦 + 七度音

| 和弦类型 | 构成 | 音程结构 | 以 C 为根音 |
|:---:|:---:|:---:|:---:|
| **大七和弦 (Maj7)** | 大三 + 大七度 | 4 + 3 + 4 | C - E - G - B |
| **属七和弦 (7)** | 大三 + 小七度 | 4 + 3 + 3 | C - E - G - B♭ |
| **小七和弦 (m7)** | 小三 + 小七度 | 3 + 4 + 3 | C - E♭ - G - B♭ |
| **半减七 (m7♭5)** | 减三 + 小七度 | 3 + 3 + 4 | C - E♭ - G♭ - B♭ |
| **减七和弦 (dim7)** | 减三 + 减七度 | 3 + 3 + 3 | C - E♭ - G♭ - A |

### 音程半音数速查

| 音程 | 半音数 | 示例 (从 C) |
|:---:|:---:|:---:|
| 小二度 | 1 | C → D♭ |
| 大二度 | 2 | C → D |
| 小三度 | 3 | C → E♭ |
| 大三度 | 4 | C → E |
| 纯四度 | 5 | C → F |
| 增四度/减五度 | 6 | C → F♯/G♭ |
| 纯五度 | 7 | C → G |
| 小六度 | 8 | C → A♭ |
| 大六度 | 9 | C → A |
| 小七度 | 10 | C → B♭ |
| 大七度 | 11 | C → B |
| 纯八度 | 12 | C → C |

## 和弦转位原理

### 什么是转位

转位是将和弦音重新排列，使不同的音作为**最低音（Bass）**：

| 转位 | 最低音 | 记号 | C 和弦示例 |
|:---:|:---:|:---:|:---:|
| **原位** | 根音 (1) | C | C - E - G |
| **第一转位** | 三音 (3) | C/E | E - G - C |
| **第二转位** | 五音 (5) | C/G | G - C - E |

### 转位的音程变化

当和弦转位时，音与音之间的音程关系会改变：

**C 大三和弦各转位的音程**：

```
原位 (C-E-G):
C → E: 大三度 (4半音)
E → G: 小三度 (3半音)
G → C: 纯四度 (5半音)  ← 回到根音

第一转位 (E-G-C):
E → G: 小三度 (3半音)
G → C: 纯四度 (5半音)
C → E: 大三度 (4半音)  ← 回到起点

第二转位 (G-C-E):
G → C: 纯四度 (5半音)
C → E: 大三度 (4半音)
E → G: 小三度 (3半音)  ← 回到起点
```

**规律**：转位只是改变音的排列顺序，三个音程（大三度、小三度、纯四度）循环出现。

## 指板基础：弦间音程关系

### 标准调弦的弦间音程

```
弦:    6弦   5弦   4弦   3弦   2弦   1弦
空弦:   E  →  A  →  D  →  G  →  B  →  E
音程:      +4度  +4度  +4度  +3度  +4度
半音:      (5)   (5)   (5)   (4)   (5)
```

**关键点**：
- 大部分相邻弦：**纯四度**（5个半音）
- 3弦 → 2弦 例外：**大三度**（4个半音）

### 同品位的音程关系

以 **5弦、4弦、3弦** 为例（同品位）：

| 品位 | 5弦 | 4弦 | 3弦 | 验证 |
|:---:|:---:|:---:|:---:|:---:|
| 0品 | A | D | G | A+4度=D, D+4度=G ✅ |
| 3品 | C | F | B♭ | C+4度=F, F+4度=B♭ ✅ |
| 5品 | D | G | C | D+4度=G, G+4度=C ✅ |
| 7品 | E | A | D | E+4度=A, A+4度=D ✅ |

**结论**：5弦→4弦→3弦，同品位时每次升高**纯四度（5半音）**

## 快速找和弦转位的方法

### 方法一：锚点定位法

**核心思想**：先找到根音位置，再根据音程关系推算其他音

#### 步骤 1：记住根音在各弦的位置

以 C 为例（从空弦开始数半音）：

| 弦 | 空弦音 | C 的品位 | 计算 |
|:---:|:---:|:---:|:---:|
| 5弦 | A | **3品** | A + 3半音 = C |
| 4弦 | D | **10品** | D + 10半音 = C |
| 3弦 | G | **5品** | G + 5半音 = C |

#### 步骤 2：从根音推算三音和五音

**公式**：
- 三音 = 根音 + 4半音（大三和弦）或 + 3半音（小三和弦）
- 五音 = 根音 + 7半音

**C 大三和弦各音位置**：

| 音 | 5弦 | 4弦 | 3弦 | 推算方式 |
|:---:|:---:|:---:|:---:|:---:|
| **C** (根音) | 3品 | 10品 | 5品 | 锚点 |
| **E** (三音) | 7品 | 2品 | 9品 | C + 4半音 |
| **G** (五音) | 10品 | 5品 | 0品 | C + 7半音 |

### 方法二：指型平移法

**核心思想**：记住一个**封闭指型**（不含空弦），整体平移即可变调

以 C 和弦**第一转位**为例（5-7品区域，无空弦）：

```
C 和弦第一转位 (E-G-C):

     5弦   4弦   3弦
    ┌────┬────┬────┐
 5品│    │ G  │ C  │
    ├────┼────┼────┤
 6品│    │    │    │
    ├────┼────┼────┤
 7品│ E  │    │    │  ← 低音 (三音)
    └────┴────┴────┘
```

**整体上移 2 品 → D 和弦第一转位 (F♯-A-D)**：

```
     5弦   4弦   3弦
    ┌────┬────┬────┐
 7品│    │ A  │ D  │
    ├────┼────┼────┤
 8品│    │    │    │
    ├────┼────┼────┤
 9品│ F♯ │    │    │  ← 低音 (三音)
    └────┴────┴────┘
```

> **注意**：含空弦的指型（如开放 C 和弦）无法直接平移，需使用封闭指型。

### 方法三：相邻弦推算法

**利用弦间纯四度关系快速推算**：

```
已知: 5弦某品是 X 音
推算: 4弦同品 = X + 纯四度
      3弦同品 = X + 纯四度 + 纯四度 = X + 小七度

例: 5弦3品 = C
    4弦3品 = C + 4度 = F
    3弦3品 = C + 小7度 = B♭
```

**逆向推算**（往低音弦）：

```
已知: 3弦某品是 X 音
推算: 4弦同品 = X - 纯四度 = X + 纯五度
      5弦同品 = X + 纯五度 + 纯五度 = X + 大二度

例: 3弦5品 = C
    4弦5品 = C + 5度 = G
    5弦5品 = C + 大2度 = D
```

## 转位的实际应用

### 应用 1：平滑的低音进行

**原始进行**：C → Am → F → G

**问题**：低音跳跃大（C → A → F → G）

**优化方案**：用转位让低音平滑上行

```
和弦:    C      Am/E     F       G
低音:   (C)  →  (E)  →  (F)  →  (G)
说明:   原位    Am第一   原位    原位
              转位

低音线: C → E → F → G (级进上行，更流畅)
```

**Am/E 指型**（Am 第一转位，E 为低音）：

```
Am/E (E-A-C):

     5弦   4弦   3弦
    ┌────┬────┬────┐
 5品│    │    │ C  │
    ├────┼────┼────┤
 6品│    │    │    │
    ├────┼────┼────┤
 7品│ E  │ A  │    │  ← 低音
    └────┴────┴────┘

音程: E(5弦7品) → A(4弦7品): 纯四度(5半音)
      A(4弦7品) → C(3弦5品): 小三度(3半音)
```

### 应用 2：利用共同音平滑切换

**目标**：C → Am 进行，利用共同音实现平滑切换

**C 原位 (0-3品)**

```
     5弦   4弦   3弦
    ┌────┬────┬────┐
 0品│    │    │ G  │
    ├────┼────┼────┤
 1品│    │    │    │
    ├────┼────┼────┤
 2品│    │ E  │    │  ← 共同音
    ├────┼────┼────┤
 3品│ C  │    │    │  ← 根音
    └────┴────┴────┘

C 和弦: C - E - G
```

**Am 原位 (0-2品)**

```
     5弦   4弦   3弦
    ┌────┬────┬────┐
 0品│ A  │    │    │  ← 根音
    ├────┼────┼────┤
 1品│    │    │    │
    ├────┼────┼────┤
 2品│    │ E  │ C  │  ← E、C 都是共同音
    └────┴────┴────┘

Am 和弦: A - C - E
共同音: C 和 E
```

> **优势**：4弦2品的 E 是共同音，切换时只需移动两根手指

**Am/E (E为低音，5-7品)**

```
     5弦   4弦   3弦
    ┌────┬────┬────┐
 5品│    │    │ C  │  ← C 是共同音

共同音: E 和 C (两个共同音！)
```

### 应用 3：丰富和声色彩

| 场景 | 推荐转位 | 原因 |
|:---:|:---:|:---:|
| 歌曲开头/结尾 | 原位 | 稳定感强 |
| 过渡和弦 | 第一转位 | 流动性好 |
| 营造悬念 | 第二转位 | 不稳定，有张力 |

## 练习建议

### 第一阶段：熟悉音位
1. 在 5-4-3 弦上找出 C、E、G 的所有位置
2. 闭眼随机说出某弦某品的音名

### 第二阶段：转位切换
1. 依次弹奏：原位 → 第一转位 → 第二转位
2. 用节拍器，每拍切换一个转位

### 第三阶段：移调练习
1. 将 C 和弦指型整体移动，变成 D、E、F 等和弦
2. 练习其他调的三种转位

### 第四阶段：实战应用
1. 选一首熟悉的歌，尝试用不同转位演奏
2. 设计平滑的低音进行
