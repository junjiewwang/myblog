# 🎸 音级与功能和声

> 音级是音阶中每个音的位置编号，用于描述音与主音的关系

## 自然大调音级

| 音级 | 名称 | 功能 | 与主音关系 |
|:---:|:---:|------|:---:|
| **Ⅰ** | 主音 (Tonic) | 调性中心，最稳定 | 纯一度 |
| **Ⅱ** | 上主音 (Supertonic) | 过渡性，倾向Ⅰ或Ⅲ | 大二度 |
| **Ⅲ** | 中音 (Mediant) | 决定大/小调色彩 | 大三度 |
| **Ⅳ** | 下属音 (Subdominant) | 次稳定，推动进行 | 纯四度 |
| **Ⅴ** | 属音 (Dominant) | 强烈倾向主音 | 纯五度 |
| **Ⅵ** | 下中音 (Submediant) | 关系小调主音 | 大六度 |
| **Ⅶ** | 导音 (Leading Tone) | 强烈倾向主音（半音） | 大七度 |

## 音级与和弦

> 每个音级上可以构建三和弦，形成调内和弦

| 音级 | 和弦性质 | C大调示例 | 功能 |
|:---:|:---:|:---:|------|
| Ⅰ | 大三和弦 | C | 主功能 |
| Ⅱ | 小三和弦 | Dm | 下属功能 |
| Ⅲ | 小三和弦 | Em | 主功能 |
| Ⅳ | 大三和弦 | F | 下属功能 |
| Ⅴ | 大三和弦 | G | 属功能 |
| Ⅵ | 小三和弦 | Am | 主功能 |
| Ⅶ | 减三和弦 | Bdim | 属功能 |

## 功能和声

```
┌─────────────────────────────────────────────────┐
│                    和声功能                      │
├─────────────────────────────────────────────────┤
│  主功能 (T)    →    下属功能 (S)    →    属功能 (D)    →    主功能 (T)  │
│   Ⅰ Ⅲ Ⅵ              Ⅱ Ⅳ                 Ⅴ Ⅶ               Ⅰ        │
│  (稳定)            (推动)              (紧张)            (解决)       │
└─────────────────────────────────────────────────┘
```

**功能进行规律**：
- **T → S → D → T**：最经典的和声进行
- 属功能（Ⅴ、Ⅶ）有强烈的解决倾向，需要回到主功能
- 下属功能（Ⅱ、Ⅳ）起推动作用，常接属功能
