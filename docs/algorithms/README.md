# 🔢 算法

> 记录算法的思想、设计、实现与应用。单篇不止于题解：讲思想 → 讲设计 → 讲实现（多种写法）→ 讲复杂度 → 讲变体与应用，配执行过程可视化动画。

## 文章统一结构

每篇固定 7 个区块，方便横向对比与系统复习：

| 区块 | 内容 |
|------|------|
| ① 一句话思想 | 核心 intuition，30 秒看懂 |
| ② 可视化动画 | 执行过程 GIF 逐帧拆解 |
| ③ 多种实现 | 同一问题的多种写法 + 完整代码 |
| ④ 复杂度分析 | 时间/空间 + 复杂度"从哪里来"的推导 |
| ⑤ 对比与选择 | 工程视角：什么场景用哪种 |
| ⑥ 变体与应用 | 该算法作为"零件"的一族问题 |
| ⑦ 易错点 | 断链、成环、边界条件等 |

## 可视化动画生成

算法动画由可复用脚本管线自动生成（Python + Pillow），源码见仓库 `scripts/algo-visualizer/`：

```
算法状态快照序列 → linked_list 渲染器 → visualizer GIF 导出
```

未来新增链表类算法动画只需产出状态快照，渲染与导出逻辑完全复用。

```bash
cd scripts/algo-visualizer && python3 reverse_linked_list.py
```
