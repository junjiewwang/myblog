## 技术项目（个人研究与实践）

> 基于工作中观察到的真实痛点，业余独立设计与实现，完整代码与设计文档可展示。

### Agent 远程控制平面

**痛点**：大量 Java Agent 实例缺乏统一管控，配置变更需逐个重启  
**方案**：Protobuf + 长轮询分布式管控架构，AtomicReference 无锁热切换 + 指数退避重连 + 4 态连接状态机  
**成果**：配置下发 P99 < 1s，指令到达率 > 99.5%

### Arthas 生命周期管理

**痛点**：Arthas 人工逐台操作，状态黑盒，异常难恢复  
**方案**：6 态生命周期状态机，启动看门狗 + Tunnel 断线治理 + 幂等分发与任务时效校验  
**成果**：连接成功率 ~85% → 99.9%+，故障可自愈

### 分布式 Arthas Tunnel 架构升级

**痛点**：跨节点 WebSocket 代理连接失败率高  
**方案**：定位 Redis Lua cjson 19 位时间戳精度丢失，统一 13 位 UnixMilli；内部专用入口解耦内外协议  
**成果**：跨节点代理延迟 < 50ms，连接成功率 99.9%+

### AI Agent 运维自动化工具集

**痛点**：运维操作分散在 6+ 平台，单次排查 20~30 分钟  
**方案**：设计 AI Agent Skills 体系（10+ Skills），CDP 浏览器自动化复用认证会话（启动开销 2s→50ms）、语义路由 + 通用执行器、跨系统数据流编排、通用骨架 + 扩展点架构  
**成果**：排查耗时 20 分钟→10 秒；新场景开发成本降低 80%
