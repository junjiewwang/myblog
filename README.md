# My Blog

个人技术博客，基于 [Docsify](https://docsify.js.org/) 构建。

## 📚 内容分类

- **☕ Java & Spring** - SpringBoot 分包部署、Spring 代理问题、Swagger-UI 整合
- **🐹 Go 语言** - Go 语言完整学习指南
- **🔧 DevOps & 运维** - Docker GUI、Nginx 配置、VNC Server、Vim 命令
- **🍎 Mac 效率** - Homebrew、Alfred 使用技巧
- **🔢 算法** - 翻转链表（多种实现 + 执行过程动画）
- **🎵 音乐** - 吉他学习笔记

## 🚀 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:3000
